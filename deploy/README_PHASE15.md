# Phase 15 - 운영 데이터 등록 / 마이그레이션

## 목적

실제 회사 지침 항목을 운영자가 CSV/JSON으로 대량 등록할 수 있도록 한다.

## 권장 운영 절차

1. `/migration` 화면에서 CSV 양식을 다운로드한다.
2. 회사 지침 항목을 입력한다.
3. `검증만 실행`으로 필수 필드, 중복 ID, 검색 키워드 누락을 확인한다.
4. 오류가 없으면 `검증 후 대기 배치 등록`을 실행한다.
5. 반영 방식을 선택한다.
   - upsert: 기존 ID 덮어쓰기
   - append: 기존 데이터 뒤에 추가
   - replace: 전체 교체
6. `현재 데이터에 반영`을 실행한다.
7. 검색 화면에서 새 항목이 노출되는지 확인한다.

## 백업

커밋 전 `backend/data/migration_backups`에 기존 `standard_items.json`이 자동 백업된다.
